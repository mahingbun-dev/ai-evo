# outputs/ —— 脚本产物目录

脚本输出的**文件产物**（导出的表格、生成的报告、整理后的中间文件等）统一写到本目录，
即运行时的 `{_run_dir}/outputs/`。平台组装工作区时保证本目录存在（没有会自动创建），
本地试跑时范本脚本也会防御式创建（见 `scripts/hub_package/lib/helpers.py` 的
`ensure_outputs_dir`）。

约定：

- 只写文件产物与随产物必需的附属文件，不要把大体积输入拷贝进来（输入用
  `inputs/` 原位消费即可）；
- 落盘后在标准输出 JSON 的 `files` 键注册（`{文件名: 绝对路径}`），裁判与下游
  才能发现产物；
- 本目录随单条数据评测结束与整个工作区一起清理，不持久。

本文件是脚手架说明（不要打进上传包）；你的脚本运行时写进本目录的产物文件
不受它影响。
